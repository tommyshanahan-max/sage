# The Exchange wallet — a design, not a deploy

Every screen of the wallet as one clickable phone: the Wallet widget on the
Profile page; setup (region, terms, identity on the provider's page, Face ID,
connecting a bank / card / PayPal, where received money goes); wallet home;
send, request, pay a request, accept or decline incoming money, add money,
withdraw; activity and payment detail (cancel, report a problem); payment
methods; settings, limits, help and safety, close wallet; and the money cards
and + menu in a chat room. Open `exchange-wallet-demo.html` in a browser.

Invented people and money; nothing is sent or connected. "All screens" jumps
to any of them. A real build of this, against a stand-in provider shaped like
Airwallex, is in progress on the `wallet/test-money` branch.
